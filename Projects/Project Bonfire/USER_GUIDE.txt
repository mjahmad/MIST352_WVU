WHAT IS THIS APP?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Bonfire Planner is a full-featured console application that combines
real-time NOAA weather data with a smart outdoor bonfire planning
system. It helps users decide if tonight is a good night for a fire
while improving comfort, safety, and the full bonfire experience.

It helps users:

• Check tonight’s bonfire weather conditions
• See the best time window for having a bonfire
• Calculate a Bonfire Readiness Score from live NOAA data
• Know where to sit based on wind direction
• Visualize wind direction with a terminal compass
• Estimate firewood dryness from weather trends
• Get hoodie, blanket, and comfort recommendations
• Compare tonight’s weather to historical bonfire conditions
• Receive fire safety warnings for wind, rain, and poor burn conditions
• End the night with a fun S’mores Rating summary

The app uses TWO live NOAA data sources:

1. api.weather.gov  — Real hourly and daily US weather forecast
2. NOAA GHCN       — Historical weather records from NOAA stations

HOW TO RUN THE APP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Requirements:

• .NET 10.0 SDK installed
• Internet connection (for live NOAA weather data)

Steps:

1. Open a terminal in the BonfirePlanner folder
2. Run:  dotnet run
3. Enter your location when prompted (example: Morgantown, WV)
   or press ENTER for the default location
4. Wait for NOAA weather data to load

Note:
If NOAA APIs are slow or temporarily unavailable, the app uses
fallback demo weather values so the project can still run smoothly.

MENU OPTIONS — FULL FEATURE LIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[1]  TONIGHT’S FIRE SCORE
─────────────────────────────────────
Calculates a Bonfire Readiness Score from 0–100 using:

```
 • temperature
 • precipitation chance
 • wind speed
 • humidity
 • weather conditions

 Example:
 Tonight’s Bonfire Score: 87/100
 Excellent conditions for a bonfire

 Higher scores mean better fire conditions.
```

[2]  BEST BONFIRE TIME
─────────────────────────────────────
Analyzes the evening weather forecast and recommends the
best time window for having a bonfire.

```
 Example:
 Best Time: 7 PM – 10 PM

 Uses hourly weather conditions when available.
```

[3]  WIND DIRECTION + WHERE TO SIT
─────────────────────────────────────
Uses NOAA wind direction data to help users avoid smoke.

```
 Shows:

 • wind direction
 • wind speed
 • best side to sit on
 • terminal compass visualization using N/E/S/W

 Example:
 Wind coming from: West
 Sit on the East side of the fire
```

[4]  FIREWOOD DRYNESS CHECK
─────────────────────────────────────
Estimates if your firewood conditions are good for burning.

```
 Based on:

 • recent rainfall
 • humidity
 • temperature
 • weather trends

 Example:
 Wood Dryness: Fair
 Recommendation: Use seasoned wood tonight
```

[5]  HOODIE / BLANKET RECOMMENDATION
─────────────────────────────────────
Comfort Advisor recommends what to bring for the night.

```
 Examples:

 Bring:
 ✓ Hoodie
 ✓ Blanket
 ✓ Bug Spray

 Avoid:
 ✗ Shorts
 ✗ Thin shoes
```

[6]  HISTORICAL BONFIRE COMPARISON
─────────────────────────────────────
Compares tonight’s weather to historical bonfire-friendly
nights in West Virginia using NOAA records.

```
 Shows:

 • average April bonfire temperatures
 • comparison to normal seasonal conditions
 • whether tonight is above or below ideal
```

[7]  PERFECT FIRE CONDITIONS DASHBOARD
─────────────────────────────────────
A full Bonfire Dashboard with all major information in one place.

```
 Displays:

 • current temperature
 • wind speed + direction
 • humidity
 • rain chance
 • best bonfire time
 • Bonfire Readiness Score
 • comfort level
 • S’mores Rating

 Example:

 BONFIRE DASHBOARD

 Temperature: 64°F
 Wind: 5 mph
 Humidity: 48%
 Rain Chance: 5%
 Best Time: 7 PM – 10 PM
 Fire Score: 91/100
 S’mores Rating: Elite
```

[8]  CAMPFIRE SAFETY ADVISOR
─────────────────────────────────────
Checks for unsafe bonfire conditions.

```
 Gives warnings for:

 • strong wind
 • rain approaching
 • poor burn conditions
 • unsafe fire spread risk

 Example:
 ⚠ Wind too strong tonight
 ⚠ Rain likely after 9 PM
```

[9]  S’MORES MODE
─────────────────────────────────────
A fun summary feature that gives the final vibe check
for the night.

```
 Includes:

 • S’mores Rating
 • comfort level
 • overall recommendation

 Example:
 S’mores Rating: Elite

 Tonight is perfect for a long bonfire night.
```

[0]  EXIT
─────────────────────────────────────
Safely closes the application.

FINAL PROJECT GOAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The goal of this project was to expand a simple weather-based
bonfire application into a full-featured terminal experience
using live NOAA weather data and multiple C# classes.

Instead of only checking if tonight is good for a fire,
the application helps users plan the full bonfire experience
through weather analysis, safety recommendations, comfort advice,
historical comparisons, and interactive terminal visualizations.

This project demonstrates stronger NOAA API integration,
clean console application design, and professor-style project
development similar to the Farm Project evolution.
