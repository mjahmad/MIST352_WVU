Programs used here:
1. IF_Statements: An example on how to use If, else if, and else to calculate letter grade of a given grade.
	This program has mechanisms to verify user input and handle it correctly . If user skips input or provides nothing or 	provides text instead of grade, the program handles it.
2. IF_Array_ForLoops: Same as the first program however, here we have multiple grades stored in an array. 
	This program reads grades from user, stores them in an array, then creates an other array filled with letter grades of the grades in the first array.
3. IF_Simple_Grade:Simple grade evaluation using one or more grades from the user.
4. IF_Multiple_Grades_Evaluation:Asks user for multiple grade. Evaluate and summarize.
5. The use of While loop compared to for loop when accessing an array. An example also on how to use while loop for evaluating user input until they provide a desired input.
